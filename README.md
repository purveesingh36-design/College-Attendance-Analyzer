College Attendance Analyzer

1. Project Overview

College Attendance Analyzer is a Python-based project that helps analyze student attendance records. It calculates attendance percentages, identifies students with attendance below 75%, and displays subject-wise average attendance using charts.

2. Objectives

- To calculate students' overall attendance percentages.
- To identify students with less than 75% attendance.
- To calculate subject-wise average attendance.
- To represent attendance data using charts.

3. Features

- Overall attendance percentage.
- Shortage list for students below 75%.
- Subject-wise average attendance.
- Bar chart and Pie chart visualization.
- Menu-driven interface.

4. Technologies Used

- Python
- Pandas
- Matplotlib
- CSV file

5. Requirements

- Python 3
- Pandas library
- Matplotlib library
- Visual Studio Code

6. Project Files

- "one.py" – Main Python program.
- "attendance.csv" – Student attendance dataset.
- "README.md" – Project documentation.

7. How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required libraries if needed:
   "python -m pip install pandas matplotlib"
4. Run the program:
   "python one.py"
5. Select a menu option from 1 to 4.

8. Input

The project takes student attendance information from the "attendance.csv" file.

9. Output

- Overall attendance percentages.
- List of students having attendance below 75%.
- Subject-wise average attendance.
- Bar chart and Pie chart.

10. Conclusion

The College Attendance Analyzer makes attendance management easier by calculating percentages, identifying attendance shortages, and presenting useful information through graphical charts.
